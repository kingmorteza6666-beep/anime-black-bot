# 🤖 Telegram File Sorter Bot (Node.js)

ربات تلگرام برای مرتب‌سازی اسم فایل‌ها و کپی آسان.

## ✨ امکانات
- دریافت فایل با هر فرمتی
- تکی → فقط اسم فایل با دکمه کپی
- چندتایی → مرتب‌سازی بر اساس شماره داخل اسم
- تا ۱۰۰ فایل در هر دسته

## 🚀 دیپلوی روی Render
1. ریپو رو توی گیت‌هاب آپلود کن
2. Render → New → Blueprint → ریپو انتخاب کن
3. `BOT_TOKEN` رو ست کن
4. Deploy ✅

## 🛠 دستورات
- `/start` → شروع
- `/reset` → پاک کردن بافر

# ربات مرتب‌سازی نام فایل تلگرام

ربات تلگرام با Python و aiogram برای ثبت نام فایل‌ها و مرتب‌سازی طبیعی نام‌ها؛ مناسب فهرست‌های بزرگ (مثلاً ۵۰۰۰ فایل).

## امکانات

- دریافت فایل با فرمت‌های مختلف؛ نام فایل در قالب قابل کپی ارسال می‌شود.
- نگهداری فهرست نام‌ها برای هر کاربر به‌صورت جداگانه.
- مرتب‌سازی طبیعی و بدون حساسیت به حروف بزرگ/کوچک؛ برای نمونه `Episode 2` قبل از `Episode 10` قرار می‌گیرد.
- تقسیم فهرست‌های بزرگ به چند پیام برای رعایت محدودیت طول پیام تلگرام.
- فرمان‌های `/sort`، `/count`، `/clear` و `/help`.
- SQLite برای ذخیره پایدار فهرست.
- Dockerfile و Docker Compose برای استقرار آسان.

> **رفتار مهم:** این نسخه نام فایل‌ها را ثبت و مرتب می‌کند؛ خود فایل‌ها را تغییر نام نمی‌دهد و دوباره ارسال نمی‌کند. فایل‌ها را پشت سر هم بفرست، سپس `/sort` را اجرا کن. هر فایل هنگام دریافت نیز نام خودش را فوراً می‌فرستد.

## راه‌اندازی سریع

### ۱) ساخت ربات و دریافت توکن
در تلگرام به `@BotFather` برو، دستور `/newbot` را بفرست و توکن را دریافت کن. توکن را با کسی به اشتراک نگذار.

### ۲) آپلود پروژه در GitHub
محتویات این پوشه را در یک مخزن GitHub آپلود کن. فایل `.env` را آپلود نکن؛ فقط `.env.example` در پروژه قرار دارد.

### ۳) اجرای محلی

Python 3.10 یا جدیدتر پیشنهاد می‌شود.

```bash
python -m venv .venv
```

ویندوز:
```bash
.venv\Scripts\activate
```

لینوکس / مک:
```bash
source .venv/bin/activate
```

نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

تنظیم توکن:
- از `.env.example` یک کپی با نام `.env` بساز.
- مقدار `BOT_TOKEN` را با توکن واقعی ربات جایگزین کن.

اجرا:
```bash
python bot.py
```

### ۴) استفاده

1. به ربات برو و `/start` بزن.
2. یک فایل بفرست: نام همان فایل در کادر قابل کپی ارسال می‌شود.
3. چند فایل را پشت سر هم بفرست.
4. `/sort` را بزن تا همه نام‌های ثبت‌شده به ترتیب طبیعی، شماره‌گذاری و در چند پیام ارسال شوند.
5. `/count` تعداد نام‌ها را نشان می‌دهد.
6. `/clear` فهرست نام‌ها را پاک می‌کند تا دور جدیدی شروع کنی.

مثال مرتب‌سازی:
```text
Renegade Immortal 01
Renegade Immortal 04
Renegade Immortal 08
Renegade Immortal 10
```

## اجرا با Docker

1. `.env.example` را به `.env` کپی کن و توکن را وارد کن.
2. اجرا:
```bash
docker compose up -d --build
```
3. مشاهده گزارش:
```bash
docker compose logs -f
```

فهرست در `data/files.db` نگهداری می‌شود.

## نکات امنیتی و نگهداری

- `.env` و توکن ربات را هرگز در GitHub قرار نده.
- اگر توکن به‌اشتباه منتشر شد، آن را از BotFather باطل و توکن تازه بگیر.
- ربات به‌طور پیش‌فرض فایل‌ها را دانلود یا نگهداری نمی‌کند؛ فقط نام فایل‌ها را در دیتابیس ثبت می‌کند.
- برای شروع فهرست جدید، `/clear` را بزن.
- اگر چند بار یک فایل با همان نام بفرستی، همه موارد در فهرست باقی می‌مانند.
